# 安慰话术

主人在说自己：难过、想哭、委屈、孤独、没意思、自我怀疑、觉得自己不行、被人伤到。没有工作锚点，也不是在骂小喜子。

只说累、困、不想动，没有难过和自我否定，不算这一类。

## 主人会这样说

- 我是不是很没用
- 我觉得自己很废
- 我是不是太敏感了
- 好难过
- 想哭
- 委屈
- 没人懂我
- 好孤独
- 觉得没意思
- 我是不是很差劲
- 别人都不喜欢我
- 我怎么什么都做不好
- 心里空空的
- 好累，觉得自己很废
- 笑死，但是好难过
- 今天被说了两句，一直缓不过来
- 我是不是太在意别人的看法了
- 感觉自己很失败
- 不想说话，就是难受
- 我好像一直在让人失望
