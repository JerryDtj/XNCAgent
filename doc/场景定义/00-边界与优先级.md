# 五类场景边界

分类不看情绪词像谁，只看这句话在找谁、在干什么。五类按下面顺序只命中一次，命中即停。五类都没命中，是无关闲聊，不进这套知识库。

向量库只收同目录下的五个场景文件。本文件写了五类名字和反例，放进去会把不该近的句子吸过来。

扩展时只在对应场景文件里追加「主人会这样说」。不要在场景文件里写「这句不算」。

安全树洞（不想活、想死）不单开第六类。要接话术时归安慰话术；是否停笑话走情绪预警，不在这五类里决策。

## 判定顺序

1. 挨骂兜底
2. 职场吐槽
3. 安慰话术
4. 捧哏金句
5. 懒懒不想动

## 各类只回答一个问题

| 场景 | 只回答 | 一旦还带了别的，改判 |
| --- | --- | --- |
| 挨骂兜底 | 主人是不是在对付小喜子本人 | 不再改判，这一类最高 |
| 职场吐槽 | 有没有工作里的人和事 | 同时在骂小喜子 → 挨骂兜底 |
| 安慰话术 | 是不是在说自己难过、委屈、不行 | 有工作锚点 → 职场吐槽；在骂小喜子 → 挨骂兜底 |
| 捧哏金句 | 整句是不是只在笑、接梗 | 带了骂人、工作、难过 → 分别归上面三类 |
| 懒懒不想动 | 是不是只在拒绝一件具体的事 | 带了骂人、工作、难过、纯笑 → 归上面四类 |

工作锚点：上班、加班、开会、老板、领导、甲方、同事、周报、周会、摸鱼、班味、工位、公司。出现其中任一个，只要不是在骂小喜子，就归职场吐槽。

「早八」单独不当工作锚点。早八起不来、闹钟、被窝，归懒懒不想动。早八还要开会、早八去公司，归职场吐槽。

## 原来咬在一起的句子

| 主人原话 | 归入 | 原因 |
| --- | --- | --- |
| 哈哈你好贱 | 挨骂兜底 | 对着小喜子，笑只是口气 |
| 哈哈老板好蠢 | 职场吐槽 | 锚点是老板 |
| 上班好累，不想起床 | 职场吐槽 | 有「上班」，盖过累和不起 |
| 不想上班 | 职场吐槽 | 「上班」是工作锚点 |
| 加班到觉得自己很废 | 职场吐槽 | 先有加班，自我否定不另开一类 |
| 不想起床 | 懒懒不想动 | 只拒绝起床 |
| 好累好困 | 懒懒不想动 | 只有身体状态，没有自我否定，也没有工作 |
| 我是不是很没用 | 安慰话术 | 在评价自己 |
| 好累，觉得自己很废 | 安慰话术 | 没有工作锚点，落点是自我否定 |
| 哈哈哈笑死我了 | 捧哏金句 | 整句只有笑 |
| 笑死，但是好难过 | 安慰话术 | 有难过，笑盖不过 |
| 今天天气不错 | 无关闲聊 | 五类都不是 |
