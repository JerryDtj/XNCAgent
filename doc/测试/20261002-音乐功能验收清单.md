## 一、设置面板

| # | 步骤 | 预期结果 | 结果 | 备注 |
|---|------|----------|------|------|
| 1 | 看侧边栏"在线"状态旁边 | 有一个齿轮图标（设置入口） | | |
| 2 | 点击齿轮 → 再点"在线"旁边的退出菜单区域 | 弹出设置面板；面板首项是"音乐播放"开关，**默认开启**，开关下方有"播放将使用网络流量"之类的提示文字 | | |

| 4 | 把开关拨回开 | 开关恢复开启 | | |

## 二、桌面端音乐播放

## 三、移动端形态（电脑 DevTools 模拟）

> Chrome 按 F12 打开开发者工具 → 点工具栏上的"手机/平板"图标（Toggle Device Toolbar）→ 顶部设备选 iPhone（任意型号）。页面会变成手机布局。

| # | 步骤 | 预期结果 | 结果 | 备注 |
|---|------|----------|------|------|
| 10 | 手机模拟模式下发：「领导周末又甩过来一堆PPT让我改，真累」 | 聊天**对话流里**出现一张特殊消息卡片：小喜子头像 + 配曲文案 + 播放器，**不是**右下角气泡 | | |

| 13 | 按住迷你播放器拖动 | 可以拖到屏幕任意位置，松手停住 | | |
